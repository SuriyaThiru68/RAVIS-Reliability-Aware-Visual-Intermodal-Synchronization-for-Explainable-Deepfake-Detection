    RAVIS
    Reliability-Aware Visual-Intermodal Synchronization for Explainable Deepfake Detection
    Random Forest MediaPipe Flask OpenCV
    ✨
    Features
    Everything this system can do
    Video Upload Interface
    Upload any video file directly from the browser using drag-and-drop or file picker. Supports MP4, AVI, MOV, MKV, WebM up to 500 MB.
    Face Detection
    Automatically detects faces in every video frame using MediaPipe FaceMesh — 478 precise landmarks including full lip contour tracking.
    Visual Feature Extraction
    Computes Mouth Aspect Ratio (MAR), lip velocity, lip event count, head pose, face area, and temporal entropy from detected face landmarks.
    Audio Feature Extraction
    Extracts MFCC (13 coefficients), Mel spectrogram, RMS energy, Zero Crossing Rate, spectral centroid, and speech activity from the audio track using librosa.
    Audio-Visual Sync Analysis
    Checks whether lip movements match the audio using cross-correlation, Dynamic Time Warping (DTW), and cosine similarity. The core deepfake signal — real speech is always in sync.
    Machine Learning Classification
    Uses a trained Random Forest model (200 trees, 74 features) to classify the video as REAL or FAKE. Returns probability scores and confidence percentage.
    Explainability
    Every result comes with a plain-English explanation, feature contribution bars showing what triggered the decision, reliability grade, and suspicious timestamps with sync scores.
    REST API Backend
    Flask-based async API handles file uploads, background processing, and job polling. Endpoints: POST /api/analyze, GET /api/status/{id}, POST /api/realtime_score.
    Responsive Web Frontend
    Clean HTML/CSS/JS interface with sidebar navigation, drag-and-drop upload, live camera recording, rolling charts, analysis history, and downloadable reports.
    Live Camera Detection
    Real-time webcam lip tracking using MediaPipe in the browser. Records video+audio via MediaRecorder, then sends to the full backend pipeline for accurate deepfake analysis.
